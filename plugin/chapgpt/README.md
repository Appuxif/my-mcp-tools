# My MCP — персональный ChatGPT-плагин

Этот пакет объединяет **существующее подключение My MCP Tools** с семью
практическими инструкциями: Ubuntu, Blender, Chrome, терминал,
Agent Network и два опциональных workflow для PyCharm MCP.

## Структура

- `.app.json` — **исходная привязка зарегистрированного приложения** (не менять ID).
- `.codex-plugin/plugin.json` — единственный манифест плагина.
- `skills/` — семь скиллов и их локальные справочники.

Дополнительный скилл `skills/agent-network/` описывает административную
регистрацию агентов через Dashboard или авторизованное Chrome-расширение
(`register_agent` отсутствует в native MCP), управление командами,
перевыпуск токенов, сообщения, контекст и временные Notes (48 часов).
Для Code Review есть отдельная инструкция: накапливать замечания в черновике,
финализировать одну записку и только после этого вручную отправлять ее
`note_id` разработчику в тексте `send_message`. Создание/финализация Notes
никаких уведомлений не генерирует. Он также описывает wake через
Chrome-расширение (ChatGPT) и локальный CLI-sidecar (Codex). Скилл описывает адаптеры, но не устанавливает и
не запускает их автоматически.

## PyCharm MCP (необязательный)

Новые скиллы `pycharm-code-insight` и `pycharm-refactor-verify` описывают
семантический поиск и Call Hierarchy, IDE-инспекции, умное
`rename_refactoring`, Run Configurations и безопасные изменения в открытом
проекте. **PyCharm MCP может вообще отсутствовать, быть выключен,
недоступен или показывать другой проект.** Скиллы не делают его обязательной
зависимостью: перед вызовом проверяют `list_servers` / `list_tools` /
`get_tool_schema` и `projectPath`. При недоступности продолжают работу
через Terminal MCP. Подключение PyCharm не добавляется в `config/mcp.json`
автоматически и не требует установки IDE при обычной работе с кодом.

**Terminal лучше** для Git, CI/pytest, командных пайплайнов,
массовых изменений файлов, запуска процессов, Docker, установки пакетов и
удалённых файлов. PyCharm лучше для разрешения символов, иерархии вызовов
и семантического переименования при корректно открытом проекте.

Официальная документация: https://www.jetbrains.com/help/pycharm/mcp-server.html

## Использование

Пакет использует уже зарегистрированное MCP-подключение из `.app.json`.
Он не разворачивает MCP-сервер, не содержит ключей и не меняет настройку
туннеля. Для вызовов инструментов должны быть доступны подключённый My MCP
Tools и нужные дочерние серверы (если включены пользователем).

Перед задачей агент обнаруживает доступные серверы через `list_servers`,
затем изучает `list_tools` и `get_tool_schema`. Доступность Blender, Chrome, PyCharm, Terminal и Ubuntu Desktop
может различаться: ни один из дочерних серверов нельзя считать
обязательно установленным.

### Обновление скиллов

Исходники хранятся в каталоге репозитория `skills/`.
При обновлении содержимого повторно скопируйте соответствующие папки в
`plugin/chapgpt/skills/`. Эти файлы — **снимок**, а не ссылки.
Для распространения актуального навыка обновите версию
`plugin/chapgpt/.codex-plugin/plugin.json`, пересоберите локальный архив
`plugin/chapgpt/MyMCP.zip` из `.app.json`, `.codex-plugin/`, `skills/`
и `README.md`, затем обновите установленную версию плагина.
**Изменение репозитория и ZIP само по себе не обновляет уже установленный
в ChatGPT плагин.**

### Приватность

Плагин имеет доступ к интерактивным действиям: чтению интерфейсов и файлов,
выполнению команд, редактированию 3D-сцен и управлению браузером. Подключайте
его только к доверенным личным рабочим окружениям. MCP Bridge и его
`config/mcp.json` не входят в пакет.

## Что не включено

Не добавлены вымышленные URL сайта, политики конфиденциальности, условий
использования и поддержки. Для публичного размещения эти данные нужно
предоставить отдельно; локальному ZIP с зарегистрированным приложением
они не требуются.
