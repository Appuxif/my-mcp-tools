# My MCP — персональный ChatGPT-плагин

Этот пакет объединяет **существующее подключение My MCP Tools** с четырьмя
практическими инструкциями для управления Ubuntu, Blender, Chrome и терминалом.

## Структура

- `.app.json` — **исходная привязка зарегистрированного приложения** (не менять ID).
- `.codex-plugin/plugin.json` — единственный манифест плагина.
- `skills/` — четыре скилла и их локальные справочники.

## Использование

Пакет использует уже зарегистрированное MCP-подключение из `.app.json`.
Он не разворачивает MCP-сервер, не содержит ключей и не меняет настройку
туннеля. Для вызовов инструментов должны быть доступны подключённый My MCP
Tools и нужные дочерние серверы (если включены пользователем).

Перед задачей агент обнаруживает доступные серверы через `list_servers`,
затем изучает `list_tools` и `get_tool_schema`. Доступность Blender, Chrome,
Terminal и Ubuntu Desktop может различаться — не следует считать
установленными все четыре дочерних сервера.

### Обновление скиллов

Исходники хранятся в каталоге репозитория `skills/`.
При обновлении содержимого повторно скопируйте соответствующие папки в
`plugin/chapgpt/My MCP/skills/`. Эти файлы — **снимок**, а не ссылки.

### Приватность

Плагин имеет доступ к интерактивным действиям: чтению интерфейсов и файлов,
выполнению команд, редактированию 3D-сцен и управлению браузером. Подключайте
его только к доверенным личным рабочим окружениям. MCP Bridge и его
`config/mcp.json` не входят в пакет.

## Что не включено

Не добавлены вымышленные URL сайта, политики конфиденциальности, условий
использования и поддержки. Для публичного размещения эти данные нужно
предоставить отдельно; локальному ZIP с зарегистрированным приложением
они не требуются.
