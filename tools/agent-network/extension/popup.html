Можно выбрать агента сервера для привязки или локального агента для переноса.
Перенос существующего агента

История ChatGPT не копируется. Имя, ID агента, сообщения и задачи в Agent Network сохранятся.

Привязка и перенос не прерывают генерацию ответа и не отправляют сообщений. Если у пустой страницы ещё нет ID беседы, расширение дождётся первого сообщения пользователя, затем покажет точный URL для подтверждения привязки — без служебной переписки. Инструкции можно отправить кнопкой; первый PUSH тоже представит агента. Плавающее окно открывается только этой кнопкой.
РАСПИСАНИЕ · ЭТОТ АГЕНТ
Работает, пока открыт Chrome и чат агента. Пропускает занятой чат и черновики, повторяет попытку в следующем интервале. «Стоп» агента приостанавливает отправку.
КОМАНДЫ · УПРАВЛЕНИЕ АДМИНИСТРАТОРОМ
Создание нового агента и назначение команд требуют admin-token сервера. Существующий агент продолжит работать со своим токеном. Токен хранится только в расширении, отдельно для каждого сервера.
Администратор не подключён
Можно выбрать несколько команд. Для удаления нажми × рядом с названием и сохрани. Агент должен состоять минимум в одной команде.
Проверяю состояние…
Пробуждение передаёт только сигнал. Агент получает и подтверждает сообщения через MCP. Приватный токен сохраняется в браузере и попадает в первоначальный промпт чата.
